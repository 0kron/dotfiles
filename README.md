# 0kron
## Minimal Arch + Sway Setup

### Software

- **WM:** Sway
- **Distro**: Arch Linux
- **Shell**: ZSH
- **Editor**: Neovim (>0.12.0)
- **Term Emulator**: Kitty + Tmux
- **Fonts**: Cousine NF, GoMono NF.
- **Launcher**: wmenu
- **Bar**: Waybar

### Dependencies

- **System Info**: acpi, htop, man-pages, man-db.
- **System Admin**: stow, brightnessctl, wl-clipboard, keyd.
